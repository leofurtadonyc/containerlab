## Workflow distinctions to preserve

- **Read-only evidence workflows:** overview, topology, policies, devices, services, dossiers, reports, situation, investigation, digest, consistency, quality, stability, maintenance planning.
- **Bounded workflow management:** workflow lifecycle records and transitions.
- **Actual state-changing backend actions:** preview creation, validation creation, workflow lifecycle creation/transitions, safe action creation/approval/execution/cancel/reject, rollback creation/approval/execution/cancel/reject.
- **Platform-only actions:** safe action and rollback currently write platform application state/intent overlay, not device or controller config.
- **Nonexistent real device actions:** no broad network actuation, autonomous remediation, full device rollback, or production approval workflow should be implied.
